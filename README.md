## Страницы

| Страница | Содержание |
|---|---|
| `index.html` | hero-блок, преимущества, популярные товары, информационный блок |
| `catalog.html` | сетка карточек товаров, статический блок фильтров, модальное окно быстрой заявки |
| `product.html` | изображение, описание, цена, кнопка заявки, таблица характеристик |
| `order.html` | форма оформления заявки |
| `contacts.html` | адрес, телефон, e-mail, форма обратной связи |

На всех страницах одинаковые шапка с меню и подвал, подключён общий `css/style.css`, задан уникальный `title` и `description`.

## Что реализовано по методическим указаниям

- **Семантика:** `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`; на каждой странице один `main`.
- **Навигация:** единое меню на всех страницах, якорные ссылки `index.html#advantages`, `index.html#popular`, `index.html#contacts`.
- **Карточки:** название, описание, цена, кнопка «Подробнее», бейджи «Хит», «Новинка», «Скидка».
- **Таблица:** `caption`, `thead`, `tbody`, `th`, `td`, оформление в CSS.
- **Формы:** поля имя, e-mail, телефон, тема или товар, комментарий, согласие; у каждого поля `label` с `for`, атрибуты `name`, `required`, `type="email"`.
- **Модальное окно:** элемент `<dialog>`.
- **CSS:** переменные в `:root`, состояния `:hover`, `:focus-visible`, `:disabled`.
- **Flexbox:** меню, группы кнопок.
- **Grid:** сетка каталога, блок преимуществ, раскладка каталога с фильтрами, страница товара, контакты.
- **Позиционирование:** `relative` (карточка), `absolute` (бейдж), `sticky` (шапка и фильтры), `fixed` (кнопка «Наверх»), `z-index`.

## Самостоятельные доработки

- БЭМ-модификаторы карточек (`product-card--new`, `product-card--discount`) с разным оформлением бейджей;
- хлебные крошки на внутренних страницах;
- sticky-блок фильтров в каталоге и фиксированная кнопка «Наверх»;
- подсветка ошибочных полей формы через `aria-invalid` и видимый фокус для доступности;
- таблица характеристик с чередованием строк и подсветкой при наведении;
- адаптивная раскладка для узких экранов (`@media`).


## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.
