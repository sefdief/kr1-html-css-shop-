# Контрольная работа №3

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой сайт интернет-справочника, разработанную с использованием Bootstrap.

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap через CDN;
- подключение `css/styles.css`;
- шапка страницы;
- Bootstrap-навигация;
- hero-блок на сетке;
- подвал страницы.

## Используемые технологии

- HTML;
- Bootstrap;
- CSS;
- Git;
- GitHub.
